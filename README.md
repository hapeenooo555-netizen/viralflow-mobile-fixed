## Quick Start

1. Open `index.html` in your browser
2. Select a platform (TikTok, WhatsApp, Affiliate, etc.)
3. Enter your prompt in Swahili or English
4. Click "Generate" to create viral content
5. Copy or export your content

## Technologies

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Groq API (AI Generation)
- **CDN**: Cloudflare Workers (Optional)
- **Deployment**: Vercel, Netlify, or GitHub Pages

## Deployment

### Deploy to Vercel (Recommended)

```bash
npm install -g vercel
vercel
```

### Deploy to Netlify

```bash
npm run build
# Deploy the dist folder to Netlify
```

### Deploy to GitHub Pages

1. Go to Settings → Pages
2. Select main branch as source
3. Your site will be live at: `https://hapeenooo555-netizen.github.io/viralflow-mobile-fixed`

## API Integration

The app currently uses mock AI generation. To enable real AI:

1. Get a Groq API Key from [console.groq.com](https://console.groq.com)
2. Update `script.js` with your API endpoint
3. Configure CORS headers in your backend
